# SHE-READY AI – Financial Literacy Assessment

## Purpose

This folder contains educational assessment materials designed to evaluate users' basic understanding of financial concepts.

## Planned Activities

1. Basic banking knowledge quiz.
2. Savings account questions.
3. Fixed deposit and interest questions.
4. Digital payment awareness questions.
5. Banking safety questions.

## Dataset Structure

The assessment dataset will contain:

- Question ID
- Topic
- Question
- Option A
- Option B
- Option C
- Option D
- Correct Answer
- Explanation

## Expected Outcome

The assessment module aims to identify learning gaps and recommend relevant educational topics.

The quiz is for educational purposes only and is not a measure of creditworthiness or financial capability.
