# SHE-READY AI – Digital Financial Safety

## Purpose

This folder contains fictional scam-awareness scenarios and educational resources to help women recognise potential digital financial fraud.

## Planned Scenarios

1. Fake banking KYC messages.
2. Suspicious UPI refund requests.
3. Fake lottery and prize messages.
4. Fraudulent customer support messages.
5. Suspicious payment links.
6. OTP and PIN sharing scams.

## Dataset Structure

- Scenario ID
- Scam Category
- Fictional Message
- Warning Signs
- Correct User Response
- Safety Explanation

## Expected Outcome

Users will learn to recognise suspicious messages and understand basic digital financial safety precautions.

All examples will be fictional and will not contain real personal or banking information.
