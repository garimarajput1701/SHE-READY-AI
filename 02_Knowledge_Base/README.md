# SHE-READY AI – Knowledge Base

## Purpose

This folder contains educational information that will support the SHE-READY AI financial education assistant.

## Planned Content

1. Basic financial concepts.
2. Savings account information.
3. Fixed deposits and interest.
4. Banking terminology.
5. Digital payment awareness.
6. General banking procedures.
7. Financial safety guidelines.

## Data Structure

The knowledge base will be organised using the following fields:

- Topic
- Question
- Answer
- Source
- Last Verified Date

## Important Note

Educational information will be checked against reliable sources, including official banking and financial education resources, before being used in the chatbot.
